# HTML Resume Page

## Explanation

This program creates a simple resume webpage using HTML.

It displays personal information education skills projects and hobbies.

## Problem Statement

Create a basic resume webpage using HTML elements such as headings paragraphs tables and lists.

## Features

- Displays personal information
- Displays career objective
- Displays education details
- Displays skills
- Displays projects
- Displays hobbies
- Uses tables and lists

## How It Works

The program uses different HTML elements to organize resume information.

Headings are used for different sections.

Paragraphs are used for descriptions.

A table is used to display education details.

Unordered lists are used for skills and hobbies.

An ordered list is used for projects.

## Technologies Used

- HTML5
- Web Browser

## HTML Tags Used

- <html> - Root element
- <head> - Contains page information
- <title> - Defines page title
- <body> - Contains visible content
- <h1> - Main heading
- <h2> - Section headings
- <p> - Paragraph
- <hr> - Horizontal line
- <table> - Creates a table
- <tr> - Creates a table row
- <th> - Creates table heading
- <td> - Creates table data
- <ul> - Unordered list
- <ol> - Ordered list
- <li> - List item
